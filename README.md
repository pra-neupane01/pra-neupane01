## Projects

### Queen Bee Detector — AI/ML Audio Classification
**Python · TensorFlow · Librosa**

Built an acoustic monitoring pipeline to detect queen-bee presence and hive anomalies from bee audio. Preprocessed recordings into log-mel spectrograms and MFCC features, then trained CNN classifiers for stress and hive-health states.

### SajiloYatra — Bus Travel & Ticketing Platform
**Spring Boot · PostgreSQL · Spring Data JPA**

Developed REST APIs for scheduling, trip search, seat selection, bookings, payments, e-tickets, refunds, and staff operations. Features include JWT/OAuth2 authentication, eSewa payments, PDF tickets, email notifications, dynamic seat pricing, and reporting.

### Esports Tournament Management System
**Spring Boot · React · PostgreSQL**

Built a full-stack platform for team and player management, registrations, scheduling, scoring, leaderboards, and tournament lifecycles. Added JWT security, WebSocket/STOMP notifications, participant check-in, result verification, reporting, certificates, and automated tests.
